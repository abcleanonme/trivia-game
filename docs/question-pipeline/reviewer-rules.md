# Weekly question reviewer rules

The scheduled reviewer task reads this file each run. Change the rules here, not in the task.

You are the weekly question REVIEWER for the iOS trivia app "Quizio" in repo abcleanonme/trivia-game. You are independent from the writer task: assume its questions may be wrong and check each one yourself. AI drafts live in App/Resources/originals-ai.json with a "reviewed" boolean and "source": "Quizio original (AI-drafted)".

Part 1, new batch: find open PRs titled "Weekly questions ..." (written by the weekly writer task). For each, check out its branch and review every entry with "reviewed": false that the PR added.

Part 2, backlog: then review up to 150 more of the oldest "reviewed": false entries already in originals-ai.json (about 608 remained on 2026-11-22). Branch from main, or from claude/project-thread-4c0yfi (PR #21) while that PR is still open, since it adds the new category names. Use branch claude/questions-review-YYYY-MM-DD. If /mnt/project-files/question-bank/ai-drafts-review.csv is reachable, mark the questions you reviewed there too (re-read it just before writing; other threads may edit it). Skip Part 2 on a run whose instructions say to review the new batch only. Once originals-ai.json has no unreviewed entries left, spend Part 2 on App/Resources/events.json instead (event-only questions, same "reviewed" flag), soonest events first per docs/content-updates.md.

For every question check:
- Accuracy: is the marked answer actually correct? Use web search to verify anything you're not certain of. Is exactly one choice correct (no other choice defensibly right)?
- Ambiguity and wording: clear, no trick phrasing, no time-sensitive facts likely to go stale.
- Distractors: plausible, same type as the answer, 4 choices total.
- Difficulty matches how hard it really is for an ordinary adult: easy = most adults know it or can work it out; medium = a casual fan or a good guess gets it; hard = specialist but still famous. Relabel anything mislabeled; drop trivia-nerd minutiae (exact dates, model numbers, minor characters, stats).
- Category is right, using only names in QuestionBank.preferredCategoryOrder (this includes Food, Space, Human Body, Words, Holidays, Brands, Mythology, Vehicles, Cartoons, Comics). Anime and manga questions belong in "Anime", never "Pop Culture"; move any you find. Pop Culture questions must be about 2022 or later; move older ones to the right category or drop them. Animated shows and films go in Cartoons; comic books and superheroes in Comics.
- Duplicates: same fact as anything in opentdb.json, originals.json, or elsewhere in originals-ai.json (normalize prompts; also catch same-fact rewordings).

Actions: fix fixable questions (rewrite wording, swap distractors, correct difficulty/category), then set "reviewed": true. Delete questions that are wrong and not cleanly fixable, duplicates, or unverifiable. Keep the JSON valid and the schema identical to existing entries. Run the TriviaKit tests if there is a quick way to.

Run history: read docs/question-pipeline/run-history.md first. On each writer PR you review, update that PR's row in the Writer table with the outcome (kept/fixed/removed counts). Append one row to the Reviewer table for this run, in the backlog PR if you open one, otherwise in the writer PR.
